# Rapid Novel

Rapid Novel is a desktop app to write web novel faster with Project and Content management. 
Writing story also faster with help of LLM AI with support from many providers.

## Features
- Database of Character, Item, Place, Group, and much more.
- Write Contents such as Draft, actual Chapter, and stories.
- Publish as PDF or other digital book format.
- Export and Import Project.
- AI generator for help in writing and image.
